# Sangkala

Situs portofolio untuk perusahaan fiktif **Sangkala** (Next.js, Prisma). Perusahaan ini
fiktif; label tersebut dipasang di luar situs.

Palet dan logo: [`BRAND.md`](BRAND.md). Tipografi, gerak, komponen, dan pola halaman: [`DESIGN.md`](DESIGN.md).

Halaman studi kasus untuk recruiter ada di `/tentang-proyek`. Isi nama dan tautan profil di
`projectAuthor` (`src/lib/site-content.ts`) agar tampil di halaman itu.

```bash
npm install
npm run dev
```
